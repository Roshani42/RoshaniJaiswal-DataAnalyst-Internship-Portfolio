# Data Analyst Internship Portfolio — ApexPlanet Software Pvt. Ltd.

Welcome! This repository is the master portfolio for my Data Analytics Internship at ApexPlanet Software, bringing together a full end-to-end data analytics project — from raw data to a validated, presented business story.

## 📖 Overview

Over the course of this internship, I worked with a 1,000-row sales dataset and progressed through four phases: data wrangling, exploratory analysis with SQL, deep-dive segmentation with an interactive dashboard, and finally statistical validation with business storytelling. Each phase built directly on the last, moving from raw, messy data to a stakeholder-ready presentation backed by hypothesis testing.

## 🔑 Key Learnings

- **Data quality is foundational** — nearly a third of early analysis time was spent identifying and resolving missing values, duplicate IDs, and inconsistent formatting before any real insight was possible.
- **Exploration must be paired with validation** — an assumption that looked true in exploratory charts (Grocery having a higher average order value than Electronics) turned out to be statistically insignificant once formally tested (p = 0.868), reinforcing that visual patterns alone can be misleading.
- **Segmentation reveals what aggregates hide** — overall averages masked a 9x revenue gap between High and Low Value customer segments, a finding invisible without breaking the data apart.
- **Interactivity changes how insights are consumed** — building a live-filterable Power BI dashboard (vs. static charts) made it possible to explore the data from a stakeholder's perspective, not just a builder's.
- **A good data story needs a call to action** — technical findings only become useful once translated into specific, time-bound business recommendations.

## 🛠️ Technical Skills Demonstrated

- **Data Wrangling:** Python, pandas — cleaning, deduplication, feature engineering
- **Data Analysis:** Descriptive statistics, correlation analysis, multivariate analysis (matplotlib, seaborn)
- **SQL:** Filtering, aggregation, grouping (SQLite via `sqlite3` + `pandas.read_sql_query`)
- **Statistical Testing:** Hypothesis formulation, independent T-tests (scipy), p-value interpretation
- **Business Intelligence:** Interactive dashboard design and publishing (Power BI Desktop)
- **Communication:** Data storytelling, stakeholder presentation design (PowerPoint), technical documentation (Markdown)
